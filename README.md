# Vehicle Insurance Quote Analysis (South Africa)

An analysis of how vehicle insurance premiums in South Africa vary across insurers, vehicle models and driver risk profiles, built with Excel and Power BI.

## Objective
Identify the most affordable comprehensive cover options for different driver profiles, and measure how age, gender, driving experience and claims history affect premiums.

## Scope
- **Vehicles:** 5 popular models [Toyota Hilux, VW Polo Vivo, Toyota Corolla Cross, Suzuki Swift, Ford Ranger]
- **Insurers:** []
- **Driver profiles:** 5 standardized profiles, each changing one factor from a baseline
  1. Baseline: 35, male, 15 yrs licensed, no claims
  2. Young driver: 22, male, 3 yrs licensed
  3. Gender: 35, female, 15 yrs licensed
  4. New licence: 35, male, 1 yr licensed
  5. Claims: 35, male, 15 yrs licensed, 1 claim in last 3 years

## Methodology
1. Collect quotes using Hippo.co.za , entered manually
2. Clean and structure the data in Excel
3. Build an interactive dashboard in Power BI

**Fixed variables:** same suburb, comprehensive cover, standard excess, private use, same vehicle year and mileage, same security and parking. All quotes collected on 2026-10-10.
